🚀 Laboratorio de Colisiones 2D
Simulador interactivo desarrollado con HTML5 Canvas, JavaScript y Bootstrap 5 que explora la detección y resolución de colisiones entre objetos circulares. Este proyecto fue diseñado como una herramienta educativa y experimental para visualizar conceptos de física computacional.

🧪 Casos de Estudio Implementados
El proyecto se divide en tres módulos principales que demuestran la evolución del algoritmo:

Caso A: Distancia entre Objetos: Detección base utilizando el teorema de Pitágoras para calcular la distancia entre centros.

Caso B: Colisión Colectiva: Escalabilidad del algoritmo para detectar choques simultáneos entre múltiples objetos mediante bucles anidados.

Caso C: Colisión con Rebote: Implementación avanzada de física para la respuesta al impacto, evitando que los objetos se superpongan y permitiendo rebotes dinámicos.

🛠️ Características Técnicas
Física en Tiempo Real: Cálculo preciso de colisiones mediante distancia euclidiana.

Panel de Configuración: Ajuste dinámico de la velocidad global de los objetos mediante un slider.

Métricas de Impacto: Contador de colisiones totales acumuladas por sesión.

Interfaz Interactiva: Botón de reinicio de simulación y generador de colores aleatorios (Modelo HSL) para los objetos.

Diseño Profesional: Estilizado con Bootstrap, fuentes de Google Fonts y efectos de Glassmorphism.

🖥️ Tecnologías Utilizadas
JavaScript (ES6+): Lógica de programación orientada a objetos (POO).

HTML5 Canvas: Renderizado de animaciones y gráficos 2D.

CSS3: Estilos personalizados, gradientes y diseño responsivo.

Bootstrap 5: Framework para la estructura y componentes de la interfaz.
